# Propuestas WeCode

Página web que ve cada colegio cuando recibe una propuesta de WeCode.

Los datos de cada propuesta (colegio, grados, precios) viajan dentro del link, después del `#`. Este repositorio no guarda propuestas: solo tiene la página, los textos de los programas y las imágenes.

Los links se generan desde el armador de propuestas (en claude.ai).
